# gabrielbribeiroo.github.io

Site pessoal de **Gabriel Barbosa Ribeiro de Oliveira** - founder, builder e estudante de Ciencia da Computacao na UFPB.

Online em <https://gabrielbribeiroo.github.io>

## Stack

HTML + CSS + JavaScript puro, sem build step. Tema claro/escuro e alternancia PT/EN persistidos em `localStorage`.

```
index.html      pagina unica
css/main.css    design system (tokens em :root)
js/main.js      tema, i18n, navegacao, scrollspy, reveal
images/         fotos e capas de projeto
docs/           curriculo em PDF
```

## Rodar localmente

```bash
python -m http.server 8000
```
